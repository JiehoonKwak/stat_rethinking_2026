# Statistical Rethinking local curriculum

## Goal and owners

Study Statistical Rethinking and connect its causal/Bayesian modeling habits to bioinformatics, genomics, and medicine. [Study plan](projects/_meta/study-plan.md) owns the curriculum and learning order; [Q&A index](projects/_meta/qna-index.md), [concept map](projects/_meta/concept-map.md), and [module matrix](projects/_meta/module-matrix.md) route questions and comparisons. The root README, homework, and original course scripts are upstream course material.

[Markdown modules](projects/00-foundations/README.md) are canonical agent-readable knowledge. [site/index.html](site/index.html) is the human-facing static curriculum, generated by [build_curriculum_site.py](scripts/build_curriculum_site.py). Change the Markdown owner before regenerating the presentation. Related methods share modules to reduce duplicated explanations and make statistical comparisons easier.

## Decisions in force and reasons

Each method should expose its estimand, observation model or algorithmic proxy, assumptions, shrinkage/prior/regularization, parameter roles, diagnostics, and failure modes. Do not infer a full Bayesian posterior from a method name or regularization alone. The [critic rubric](projects/_meta/critic-rubric.md) and module source maps own the detailed checks.

Keep synthesized notes and source metadata in the curriculum. [The source ledger](projects/_meta/source-ledger.jsonl) tracks provenance; raw papers, web captures, and repository snapshots belong in gitignored `projects/_sources/raw/` so agents can consult local sources without committing bulky/copyrighted originals. Community practice remains field notes, distinct from scientific evidence. The clinical module provides analysis guidance, not diagnosis or treatment recommendations.

For exact textbook claims, use [the local metadata index](book/rethinking2/README.md), then page-marked cache text and the original PDF. Cache text is generated local search material, not a replacement for the source or material to commit. NotebookLM is retrieval/synthesis assistance; important claims require the local source or primary-method evidence. Its previously recorded notebook/source inventory in AGENTS is not a fresh live check.

## Available state and evidence limits

The local tree contains nine modules (`00`–`08`), their standard Markdown templates, source metadata, and the static HTML curriculum. This is artifact availability, not learner completion or analysis reproduction.

[SPEC.md](SPEC.md) is the **completed, dated 2026-06-12 implementation record**, not an active task specification. It records structural/ledger/HTML checks and independent reviews at that time. It also records that external DOI/URL liveness was not checked and browser QA was unavailable because Playwright was absent. Those historical checks do not establish current browser behavior or current scientific validity.
