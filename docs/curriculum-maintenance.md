# Curriculum maintenance

## Publication workflow

The [study plan](../projects/_meta/study-plan.md) owns the curriculum and learning
order. Related methods share modules to reduce duplicated explanations and
support statistical comparisons; the [Q&A index](../projects/_meta/qna-index.md),
[concept map](../projects/_meta/concept-map.md), and
[module matrix](../projects/_meta/module-matrix.md) route questions and comparisons.

Module Markdown is canonical agent-readable knowledge.
[site/index.html](../site/index.html) is the human-facing static curriculum,
generated by [build_curriculum_site.py](../scripts/build_curriculum_site.py).
Change the Markdown owner before regenerating the presentation. The root README,
homework, and original course scripts are preserved upstream course material.

## Study entry

Choose the study question with the learner, then use the Q&A index and the
module’s `qa-context.md`. Follow the study plan’s foundations-first order when
no narrower question is selected. Verify important claims through the module
source map and textbook pages.

## Evidence and maintenance limits

The local tree contains the foundations and applied method modules, standard
Markdown templates, source metadata, and static HTML curriculum. Artifact
availability does not establish learner completion or analysis reproduction.

[SPEC.md](../SPEC.md) is the completed, dated 2026-06-12 implementation record,
not an active task specification. Its final verification records structural,
ledger, HTML, and independent-review checks at that time, with external DOI/URL
liveness unchecked and browser QA unavailable because Playwright was absent.
Those historical checks do not establish current browser behavior or current
scientific validity.

Verify browser interaction when maintaining the site, and external-link liveness
when depending on an external source. Generated HTML presence alone does not
establish either. Important method claims require source-map and primary-source
verification; exact textbook claims require page-marked text and the source PDF.
